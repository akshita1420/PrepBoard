prepboard desktop helper
========================

Shows the pixel car with the COMPLETE LEETCODE banner on this laptop at your nudge
time and at 9 pm (if you haven't solved 3 problems that day), plus contest reminders.

Install (one time):
  1. Unzip this folder (right-click > Extract All).
  2. Double-click "INSTALL - double-click me".
     If Windows says "Windows protected your PC": More info > Run anyway.
  3. On prepboard: overview > nudge > desktop helper > get code. Type that code
     into the black window and press Enter.

That's it. It starts with Windows and runs silently in the background.
The website does not need to be open. Your laptop just needs to be on and online.

Don't open the files in the "files" folder yourself - the installer uses them.

Remove later: run uninstall.cmd in %LOCALAPPDATA%\prepboard-helper
Server: __PREPBOARD_SERVER__
